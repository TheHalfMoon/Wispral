Core should own deterministic policy, session/epoch identity, provenance, routing, cancellation state, worker lifetime and metadata receipts. It should reuse narrow mechanisms from founder repositories rather than import several complete security, agent or media platforms. WisprSide, WisprStudio and Klaint share these contracts; product-specific data and adapters remain outside Core.

## Policy, process and network execution traces

Sentrdel's `crates/sentrdel-policy/src/narrowing.rs::validate_repository_narrowing` and `compose_base_and_repository` reuse a real ALLOW/ASK/DENY lattice. UNDECIDABLE needs explicit handling and must never become an implicit ALLOW. Extract the pure composition mechanism before considering its broader Regorus/schema stack. The source does not contain Wispral's exact tenant, voice-consent, application-target or spoken-action semantics. Add those inputs at the authority boundary and prove monotonic narrowing with independent fixtures.

`crates/sentrdel-engine/src/process_tree.rs::ContainedChild` uses process-wrap 9.1.0 process groups/Job Objects, with nix 0.31.3 on Unix. That is useful lifetime ownership; it is not proof of a network sandbox, filesystem isolation, native inference interruption or cross-platform support. `bounded_json.rs::preflight_json` scans before serde materialization. Adapt its context-specific limits to worker frames: frame bytes, string bytes, nesting, nodes and event rates. Do not inherit a large SARIF limit as a safe realtime default.

Ninerr's `packages/network-policy/src/policy.ts` normalizes an explicit route policy, evaluates URL/capability/host rules, then evaluates resolved addresses. A WeakSet prevents callers from fabricating an issued allowed decision. The missing enforcement seam is concrete: a caller can still open a socket independently unless the transport is constrained. Core must bind the selected address to the actual connection, reject redirects outside the same grant, and prevent unbrokered worker egress using a qualified OS/process design. A route function passing tests does not establish offline privacy.

Six independent synthetic fixtures executed unchanged Ninerr modules under Node 24.19.0 on Windows x64: offline denial; capability scope; URL credentials/host suffix denial; mixed/private/empty DNS denial; forged-decision denial; unknown-policy-key denial. **6/6 passed**. No actual provider socket, DNS rebinding exploit, OS egress enforcement or integrated security/release gate was tested. See [core-network-probe-results.json](core-network-probe-results.json) and [reproduce_core_policy.mjs](reproduce_core_policy.mjs).

Orcel's actual Cargo library entry is `src/sg000040.rs`, which chains earlier modules; the apparent root `lib.rs` is not the active root. This prevents a misleading whole-library transplant. Only `crates/orcel-audit/src/lib.rs::AuditLogger::record` is proposed for adaptation: metadata append/flush, with its private-path helper closure inspected before use. Flush is not fsync or tamper-proof durability. Ascout's strict engine descriptor is an artifact/capability identity seam, not independent qualification. Skilit's capture-scope inventory is a public web evidence scope, not microphone or app-context consent. SpecGrain and Diffcipline supply governance discipline and proof-before-done references, not additional product workflow runtimes.

Yamakan's ProcessOwner/native procd design demonstrates suspended start, ownership acknowledgements, Windows Job Object/AppContainer mechanisms and minimal command environment. Its own POSIX qualification limit is material. Retain it as a Windows containment comparison if Sentrdel ownership cannot meet the worker threat model. Importing the whole creative-media application would duplicate the Studio donor. [Additional review](ADDITIONAL_SOURCE_REVIEW.md) covers Aly's cancellation fixtures: accepted cancellation is not stopped work, and its durable framework is too broad for the proposed seam.

## ACP and developer-agent portability

The ACP Rust SDK at `652d1003425319c170f1e677a1ca5af6a92269bb` declares package 3.4.0. Its cancellation documentation explicitly describes cooperative behavior: successful request cancellation is not acknowledgement or proof that the agent stopped. For an accepted v2 prompt, continuing work requires the session-level cancellation notification. Preserve protocol version/capability distinctions; do not flatten every agent to one guessed interrupt action.

`agentclientprotocol/codex-acp` at `ced4c34368d271d61bbc81f4047813b4db387623` contains permission lifecycle/session-sequence state and cancel-registration race fixtures. Its broad server/client/event-handler closure argues for using the adapter through its protocol rather than copying its entire TypeScript application into Rust. `claude-agent-acp` at `a1d0eeeaad3d67a0765f4b89e3d81c1af6ca0dbb` checks that permission responses select an actually offered option. A syntactically supported bypass mode must not become Wispral policy. Prompt-injected text and a vendor permission mode cannot authorize Core actions.

Canonical 000A remains **PARTIAL**, with only limited initialization evidence. Codex, Claude Code and Gemini CLI authenticated prompt/stream/permission/cancel scenarios were **NOT_RUN** in this study. No universal compatibility or provider subscription entitlement is claimed. PTY remains a later isolated compatibility fallback; transcript strings must never become shell commands by default.

## Speech and realtime boundaries

whisper.cpp exposes a stable-looking C header, but the example stream repeatedly runs `whisper_full` over windows: that example is not proof of native incremental decoding. sherpa-onnx online `get_result` returns text whereas `get_result_all` returns a richer result. Moonshine exposes stream events and native lifecycle through its bindings. These are exact API observations, not accuracy rankings. Current source pins are research candidates and do not replace frozen B2 versions. faster-whisper is a Studio bulk worker alternative; yielding segment objects does not establish incremental recognition. Silero speech probability is not a semantic turn detector or action authority.

Two additional mandatory ASR sources remain alternatives rather than new Core engines. [openai/whisper](https://github.com/openai/whisper/blob/86098128c0b4f24f0e2aa2994de830614b474227/whisper/transcribe.py#L38) exposes `transcribe` with temperature fallback, prior-text conditioning, initial prompt and optional word timestamps. The Python/Torch/numba/tiktoken dependency boundary is appropriate for a reference/bulk worker, not a reason to replace a selected native local ABI or add implicit C0 context. [FunASR AutoModel](https://github.com/modelscope/FunASR/blob/1d066f9d560c9c93100ea6b04582e857930d893b/funasr/auto/auto_model.py#L645) builds model/tokenizer/frontend components, downloads hub configuration when not supplied locally, and `generate` routes single utterance versus VAD segmentation. Its input accepts file/URL/bytes/arrays and per-call streaming cache. Qualify a specific model/export if it fills a measured gap; disable/version-pin update/download behavior, pre-stage local artifacts, restrict input media to the admitted boundary and reject remote URLs in offline jobs. Source cache support does not prove realtime latency or actual model language quality.

[jitsi/jiwer](https://github.com/jitsi/jiwer/blob/2227002889f20f3fb19d523eeb322732cb67b431/src/jiwer/process.py) is the corrected scorer identity (the attempted jiwer/jiwer returned 404). Version 4.0.0 uses RapidFuzz and explicit transformations for word/character alignment and measures. Wrap this existing evaluation implementation rather than write edit distance from scratch, after freezing whitespace/punctuation/Arabic normalization and empty-reference semantics. Tests were inspected, not executed here. This is a prospective evaluation dependency, never a replacement of the frozen B2 scorer or new scoring authority. Exact adjacent-file hashes are in [core-adjacent-source-evidence.json](core-adjacent-source-evidence.json).

Pipecat's `pipeline/task.py` is deprecated at the inspected source; use `pipeline/worker.py::PipelineWorker`. Its cancel path queues CancelFrame and manages shutdown; external tool side effects still need a separate broker and reconciliation. LiveKit AgentSession offers session/room/interrupt semantics and protected-speech behavior. An interrupt future is not external tool rollback. Recording/tracing and provider defaults must be selected explicitly; a local deployment is not automatically an offline path. Use one session turn owner, and keep local push-to-talk usable without either full realtime stack.

Official backend documentation was read, not exercised:

| Backend | Documented integration fact | Consequence / remaining experiment |
| --- | --- | --- |
| [OpenAI Realtime](https://developers.openai.com/api/docs/guides/realtime-conversations) | WebRTC/SIP and WebSocket differ in playback handling; WebSocket clients must stop playback and truncate unheard output | Adapter owns audio-played offset and conversation truncation; no paid API trial run |
| [Gemini Live](https://ai.google.dev/gemini-api/docs/live-api/capabilities) | Live session capabilities and interruption are provider-specific | Freeze exact model/transport/codec; test partial-turn and reconnect semantics before capability exposure |
| [Deepgram Flux](https://developers.deepgram.com/docs/flux/quickstart), [turn state](https://developers.deepgram.com/docs/flux/state) | `/v2/listen`, recommended 80 ms chunks, EagerEndOfTurn / TurnResumed / EndOfTurn and turn identity | Speculative response must remain cancellable; vendor latency statements are not Wispral measurements; validate conflicting format prose against exact API |
| [AssemblyAI streaming](https://www.assemblyai.com/docs/streaming/getting-started/transcribe-streaming-audio) | Streaming session lifecycle and explicit termination; session duration affects billing | Bound idle sessions and close on cancellation; no pricing amount or latency comparison inferred |
| [Speechmatics realtime](https://docs.speechmatics.com/api-ref/realtime-transcription-websocket) | StartRecognition, AudioAdded, partial/final transcript and EndOfStream/EndOfTranscript framing | Preserve partial/final distinction, language config, region and end acknowledgement |

All cloud adapters remain optional. Never silently send a failed local job to a cloud service. Every external route needs purpose/provider disclosure and authorization bound to the data classes actually sent.

## What Core must qualify next

Use [work packets](../../../docs/strategy/WISPRAL_COPY_FIRST_WORK_PACKETS.md) and [architecture](../../../docs/strategy/WISPRAL_PLATFORM_ARCHITECTURE_REPLAN.md). First prove a fake worker's event/epoch/stop contract, a pure policy extraction and exact native capture lifecycle. No new model engine, security platform, generic agent runtime or duplicate journal is justified. Offline egress, native process absence, real agent cancellation, all speech/latency/quality and clean-install support remain **NOT_RUN**.

## Opus M5/S2/S3/S5 selection correction

Core now means shared schemas, a small optional embedded policy library and conformance fixtures. It is not a mandatory daemon or central process owner across desktop and tenant services. Retain Handy engine_supervisor for Side and VoiceStudio containment/backend ownership for Studio; Sentrdel ContainedChild is a reference/fallback experiment only. Model inventory has one schema with one implementation per product deployment; no duplicated global store. Pipecat is the sole selected realtime framework; LiveKit Agents is reference only. Ninerr policy fixtures remain preserved, but the first-release TypeScript-to-Rust port is deferred; prove offline behavior from the shipped Side binary using observed egress. Future networked connectors require actual DNS/socket/redirect enforcement, not just pure policy PASS.
