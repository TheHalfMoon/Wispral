## Packet contract

Before coding: name the exact capability and allowed changed paths; pin upstream source and full admitted closure; retain notices; run independent fixtures against the donor before adaptation; show the smallest missing boundary. Copy or wrap first, adapt only the mismatch, integrate one seam, test at the final head, improve only after evidence. Do not install every optional donor extra. Each packet records failed/skipped checks, authority, exact base/head, rollback trigger and last known readable data format. Estimated effort below is engineer judgment for a familiar contributor and excludes waiting/review; it is not measured delivery time.

## Required evidence and CI per packet

Record source-before/after differential behavior plus independent product assertions; mirroring a donor implementation is insufficient at an authority boundary. Preserve test fixtures, source hashes and native/model identity. Pure probes are not native e2e evidence. At the candidate head run applicable repository controls; once Rust exists, fmt/clippy/test with locked all-feature/all-target requirements. Add actual OS audio/insertion/process and fake/real protocol e2e only for touched capabilities. Security/correctness review cannot be delegated solely to local d1; use required independent review and retained negative fixtures. No required check may be replaced by a source-score or benchmark metric.

Use [BENCHMARK_AND_REPLAY_PROTOCOL.md](../../research/rea/2026-10-21/BENCHMARK_AND_REPLAY_PROTOCOL.md) for frozen inputs, consent, denominators, language stratification, stop measurements and prospective release limits. Record performance distributions rather than a single best run. Any target change after seeing results requires a new preregistration, not editing the old trial.
