# STT, TTS and LLM routing contracts — V3 repair

Status: proposed contracts only; no provider integration, paid service or training authorized. Opus S6. A route is explicitly configured per desktop workspace/project or authenticated Klaint tenant. There is one modality interface per runtime, one selected provider per request, and no unapproved network or paid fallback.

| Contract | Inputs and configuration | Result / unavailable behavior |
| --- | --- | --- |
| STT | Stream/request/session/epoch, audio format/channel/rate, language policy, exact backend/native/model/tokenizer/config identity, local-only/network purpose policy | Provider raw hypothesis plus typed tentative/final events, language metadata and stop outcome. Missing/failed local backend returns provider-unavailable; never silently uploads audio |
| TTS | Exact engine/model/voice/artifact/config, project-selected route, consent/purpose/retention/revocation epoch, text and output format, watermark policy | Chunk/waveform metadata, first-audio/played offset, final artifact digest and stop state. Engine selection is explicit per project; no automatic replacement of voice/model during resume |
| LLM | Purpose rewrite/dialogue/retrieval-query, tenant/workspace, allowed input classes/context budget, provider endpoint/model/revision/config, timeout/token budget, policy/consent epoch | Bounded suggestion or structured proposal with provenance; no direct side effects. Raw transcript retained. Disabled/cloud-unapproved/missing local endpoint returns provider-unavailable and editable raw text or human handoff |

Each request binds route ID, modality, session/tenant/workspace, request/epoch, source data classes, configured endpoint/provider, model ID, model artifact digest where locally available, configuration digest, consent/policy version and timeout/resource budget. Each result repeats these identities and reports actual finish/failure/cancel state. A hosted model whose weights digest is unavailable must record `PROVIDER_MANAGED_DIGEST_UNAVAILABLE` with its exposed model/revision; do not fabricate a weight hash. Such a route is disabled by default and requires explicit data/purpose/network approval and legitimate zero-cost access before any trial. No paid credential or service is inferred from source availability.

Reuse existing donor boundaries: Handy speech/model configuration and transcribe-cpp/native adapters for Side; VoiceStudio engine selection/acceptance for Studio TTS; Parlant NLPService for Klaint LLM. A local llama.cpp-compatible endpoint is an optional configured hypothesis, not a newly installed dependency or measured Arabic solution. One Python service hosts Klaint's Parlant and optional Pipecat composition; no Rust daemon hop is required per tool call. Vendor/provider plugins must not bypass tenant/policy scope.

Acceptance fixtures: disabled cloud + failed local STT emits no network request; missing LLM leaves raw text and reports unavailable; TTS resume rejects changed model/voice/consent; cross-tenant route selection denied; stale epoch output discarded; every allowed output names the exact route/model/config and actual artifact digest/status. Test configured local endpoint timeout and credentials/redirect rejection using fake transports before legitimate native/provider runs. No route promotes confidence to action authority. No new model training is in scope.
